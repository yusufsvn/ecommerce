## Tech Stack

- **Backend:** Go, REST API, JWT Authentication
- **Database:** PostgreSQL (JSONB, Full-Text Search, `pg_trgm`)
- **Storage:** MinIO (S3-compatible object storage)
- **Payment:** Iyzico API Integration
- **Frontend:** React, TypeScript, Material UI (MUI)
- **DevOps:** Docker, Docker Compose, Cloudflare Tunnels

## Key Features

- **Advanced Product Search:** High-performance search functionality utilizing PostgreSQL Full-Text Search and trigram (`pg_trgm`) indexing.
- **Secure Authentication:** Stateless authentication implemented with JSON Web Tokens (JWT).
- **Media Management:** S3-compatible file uploads and asset retrieval handled via MinIO.
- **Payment Processing:** Secure checkout and transaction flow integrated with the Iyzico payment gateway.
- **Dynamic Schemas:** Flexible product attributes stored and queried using PostgreSQL `JSONB` types.
- **Containerized Environment:** Complete multi-service orchestration (API, Database, Storage, Frontend) via Docker Compose.
